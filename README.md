# 真顔の向井さん Official Website

GitHub Pages 向けの静的サイトです。ビルド作業は不要です。

## 公開手順

1. このフォルダの内容を GitHub リポジトリのルートへアップロードします。
2. GitHub リポジトリの **Settings** → **Pages** を開きます。
3. **Deploy from a branch** を選び、公開するブランチ（通常は `main`）と `/ (root)` を指定して保存します。
4. 表示された公開URLへアクセスします。

`index.html` がトップページとして自動的に公開されます。
